Invalid JSON path

Input moves to Invalid, highlights the parse error, and keeps the user on the input screen until it is fixed.

No colors path

Valid JSON with no color tokens becomes No colors. The preview stays empty and import is disabled.

Partial failure path

The final screen changes to Needs attention, keeps the receipt, and expands failed rows first.
