このページの扱い

`docs/doc-hub.html` は文書探索の入口です。仕様書、作業台、mockup、spike、issue body、運用文書を追加・更新・削除したら、リンク、説明、分類、更新ルールの記述も同時に見直します。Markdown文書をDocsifyで読ませる場合は、`docs/_sidebar.md` も合わせて更新します。

Framer Token Importer doc hub。開発サーバーは不要で、このHTMLをブラウザで直接開けます。
