Theme Token Workbench

hardcoded color と semantic color の対応を、1行ずつ比較しながら詰めるための作業台です。 hardcoded 側は固定表示、semantic 側だけ編集対象にして、dark baseline を崩していないかを light / dark で見比べられるようにしています。

Workbench Controls

semantic value は現在の theme 側だけ編集します。light に切り替えて編集すると light 値、dark に戻すと dark 値を個別に確認できます。

比較のしかた

各 row で palette / hardcoded / semantic を横並びで見て、preview で match か差分かをその場で確認できます。

保存の単位

`Save` は semantic name と theme 別 semantic value を `localStorage` に保存します。未保存変更がある時だけ押せます。

Reset の意味

`Reset` は保存済みデータも含めて破棄し、この HTML 内の canonical data に戻します。dark baseline の見直しをやり直す時の起点です。

semantic value は現在の theme の値を編集します。alpha 付きや rgba の調整は text input 側でそのまま扱えます。
