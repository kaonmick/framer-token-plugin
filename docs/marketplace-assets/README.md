# Marketplace Assets

Framer Marketplace 申請で使う説明文と visual asset を管理する場所です。

## ファイル

- [Submission Copy](./description.md): Marketplace に入力する tagline、summary、description、Review Instructions をまとめる
- `visuals/`: Marketplace 用の画像を入れる。Framer Creator Dashboard では 1600 x 1200 の visual が必要

## 運用メモ

- 公開文言は、実装済みの color token import に限定する。
- audit、sync、variables manager など未実装の構想は、Marketplace 文言には含めない。
- visual を追加したら、どの画面を使ったかをこの README か Issue 37 に追記する。
