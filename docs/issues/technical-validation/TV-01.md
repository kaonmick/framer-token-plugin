## Goal

Color Style に token metadata を保存し、再取得・plugin reopen・rename 後も関係情報として使えるか確認する。

## Scope

- `ColorStyle.setPluginData`
- `ColorStyle.getPluginData`
- plugin reopen 後の永続性
- Color Style rename 後の metadata 維持
- style id / path / token id の復元方針

## Steps

- [ ] 検証用 Color Style を作成する
- [ ] token id / source path / style path / kind / alias path を metadata として保存する
- [ ] 同一 plugin session 内で metadata を再取得する
- [ ] plugin を閉じて開き直し、metadata を再取得する
- [ ] Framer UI で Color Style を rename し、metadata と style id の挙動を確認する
- [ ] style path と token id のどちらを主キーにすべきか判断する

## Success Criteria

- metadata を Color Style 単位で保存・復元できる
- reopen 後も metadata が読める
- rename ではリンク情報が壊れない
- style id / path / token id の復元方針を説明できる
