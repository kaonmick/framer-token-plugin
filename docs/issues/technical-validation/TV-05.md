## Goal

Framer project 内の color 使用箇所を、Plugin API からどこまで検出できるか確認する。

## Scope

- frame background color
- text color
- border color
- gradient color stops
- SVG fill / stroke
- component props の color control
- CMS color field
- raw HEX / RGB / HSL / OKLCH
- ColorStyle 参照
- ColorVariable 参照が存在する場合の扱い
- project-wide scan / selection scan

## Steps

- [ ] 検証用 project に background / text / border / gradient / SVG / component props / CMS color を配置する
- [ ] project-wide に nodes を取得できるか確認する
- [ ] selection scope で nodes を取得できるか確認する
- [ ] 各 color source の API 上の見え方を記録する
- [ ] raw color と ColorStyle reference を区別できるか確認する
- [ ] 取得できない source を `Not scannable by Framer API` として分類する
- [ ] 初期監査の対象範囲を決める

## Success Criteria

- MVP 監査として background / text / border の raw color と ColorStyle 使用を検出できるか判断できる
- 未対応領域を仕様として列挙できる
- false positive / false negative の傾向を記録できる
