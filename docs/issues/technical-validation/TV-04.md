## Goal

Framer 側で手動編集された Color Style と、プラグインが期待する token state のズレを検出できるか確認する。

## Scope

- `Synced`
- `Primitive changed`
- `Semantic outdated`
- `Semantic manually changed`
- `Missing primitive`
- `Missing semantic`
- `Metadata missing`
- `Unmanaged style`

## Steps

- [ ] synced な primitive / semantic pair を作る
- [ ] primitive を Framer UI で手動編集して検出する
- [ ] semantic を Framer UI で手動編集して検出する
- [ ] alias 先 primitive を削除して missing dependency を検出する
- [ ] semantic style を削除して missing semantic を検出する
- [ ] metadata がない Color Style を unmanaged として分類する
- [ ] UI に出すべき status 名と説明文を決める

## Success Criteria

- 最低でも `Synced` / `Outdated` / `Missing dependency` / `Unmanaged` を区別できる
- Pro の Manager UI でユーザーが次に取るべき操作を判断できる
- 自動修復できないケースを警告として明示できる
