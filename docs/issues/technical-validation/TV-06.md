## Goal

検出した raw color や primitive misuse を、semantic Color Style へ安全に置換できるか確認する。

## Scope

- raw background color -> ColorStyle
- raw text color -> ColorStyle
- raw border color -> ColorStyle
- gradient color stop -> ColorStyle
- primitive style misuse -> semantic style
- bulk replace
- preview / summary
- partial failure handling

## Steps

- [ ] raw background color を ColorStyle 参照へ置換する
- [ ] raw text color を ColorStyle 参照へ置換する
- [ ] raw border color を ColorStyle 参照へ置換する
- [ ] gradient color stop の置換可否を確認する
- [ ] 複数 node の bulk replace を試す
- [ ] preview に必要な情報を定義する
- [ ] failed node の report 形式を決める
- [ ] fix actions を初期 Pro に含めるか判断する

## Success Criteria

- 少なくとも background / border / text の主要ケースで置換できるか判断できる
- 置換対象と置換後 style を事前確認できる
- failed node を report できる
- bulk 操作の安全性を説明できる
