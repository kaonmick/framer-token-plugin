## Goal

Color Style の duplicate / delete 後に plugin metadata と依存関係がどう扱えるか確認し、仕様上の扱いを決める。

## Scope

- Color Style delete 後の検出
- Color Style duplicate 後の metadata 挙動
- missing style / unmanaged copy / duplicated managed style の分類
- 復元・警告・無視の方針

## Steps

- [ ] metadata 付き Color Style を削除する
- [ ] plugin 側で missing style として検出できるか確認する
- [ ] metadata 付き Color Style を duplicate する
- [ ] duplicate 側に metadata が複製されるか確認する
- [ ] duplicate 側の style id / path / name の挙動を記録する
- [ ] duplicate を managed とみなすか unmanaged copy とみなすか決める

## Success Criteria

- delete は missing style / missing dependency として扱える
- duplicate の挙動を仕様として説明できる
- ユーザーの既存 styles を壊さない安全な扱いを決められる
