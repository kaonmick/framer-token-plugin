## Goal

primitive Color Style の値を変更したとき、依存する semantic Color Style の実値をプラグインから安全に更新できるか確認する。

## Scope

- primitive style の `light` / `dark` 更新
- semantic style の `light` / `dark` 更新
- metadata から dependent semantic styles を逆引き
- batch update
- partial failure の検出
- semantic style 使用レイヤーの表示更新

## Steps

- [ ] primitive style と semantic style を作成する
- [ ] semantic style に alias metadata を保存する
- [ ] primitive style の `light` / `dark` を変更する
- [ ] alias metadata から dependent semantic styles を見つける
- [ ] semantic style の `light` / `dark` を更新する
- [ ] semantic style を使っているレイヤーの表示が追従するか確認する
- [ ] 複数 semantic styles の batch update を試す
- [ ] 途中失敗時の summary / failed list を設計する

## Success Criteria

- `primitive -> semantic` の一方向同期が成立する
- semantic style を使っているレイヤーの見た目も追従する
- updated / skipped / failed を記録できる
- 失敗した style をユーザーに提示できる
