UI stack 5パターン

セルは直接編集できます
UI stack 日本語名 状態の定義 UIで必要な役割
Ideal State 理想状態 全てのデータが揃い、正常に動作する最終目標の状態。 正常に完了していること、次に実行できる主要操作を明確にする。
Blank / Empty State 空状態 データが何も登録されていない初期状態。 ユーザーを次の行動へ導く誘導UIを表示する。
Loading State 読み込み中状態 データ取得中の待ち時間。 スケルトンやスピナーを使って不安を軽減する。
Partial State 部分的状態 データは一部あるが不完全で、エラーも混在している状態。 改善を促すメッセージを表示する。
Error State エラー状態 何らかの失敗が発生した状態。 原因説明とリトライ手段を提供する。

catalog_id 発生タイミング 条件 処理 ユーザー向け表示 補足
notice.oklch_converted_to_rgba parse OKLCHをFramer互換のrgba()に変換した import可 OKLCHカラーをFramer互換のためrgba()に変換しました。 失敗ではない。色差が気になる場合だけ元JSONを調整
notice.sorted_by_token_path pre-import 番号付きtokenがJSON内で番号順に並んでいない 番号順に整列 番号付きトークンは、番号順に並べて登録します。 例: blue.100 / blue.200 / blue.500。JSONの記述順ではなく、生成後のstyle pathで自然順に登録
catalog_id 発生タイミング 条件 処理 解決タイプ ユーザー向け表示 復帰・改善導線
warning.unsupported_token parse color tokenの$valueが文字列ではない 該当tokenをskip 自動skip 値が文字列ではないため、このトークンはスキップしました。 $valueをhex / rgb(a) / hsl(a) / oklch()文字列に修正
warning.unsupported_color parse 色形式が未対応、または解釈できない 該当tokenをskip 自動skip 色形式が認識できないため、このトークンはスキップしました。 hex / rgb(a) / hsl(a) / oklch()に変換
warning.unresolved_alias parse 参照先のトークンが見つからない 該当tokenをskip 自動skip 参照先のトークンが見つからないため、このトークンはスキップしました。 参照pathを修正、または参照先のトークンを追加
warning.circular_alias parse 参照先のトークンが循環している 該当tokenをskip 自動skip 参照先のトークンが循環しているため、このトークンはスキップしました。 循環しない参照関係に修正
warning.duplicate_style_name parse JSON内の複数tokenから同じFramer style名が生成される コンフリクトを提示 択一選択 同じスタイル名が複数あります。プレビューでインポートするトークンを選択してください。 プレビューでいずれか1つを選択、またはtoken pathを変更してstyle名の重複を解消
warning.dark_mode_without_light parse dark tokenに対応するlight tokenがない dark階層styleとしてimport可 確認のみ ライトモードの設定がありません。このままインポートした場合はダークモードのみのスタイルとして登録されます。 light/darkペアにしたい場合は対応するlight tokenを追加。dark階層名を残した単体styleとして扱うなら許容
warning.existing_style_conflict pre-import 同じpathのFramer Color Styleが既に存在する コンフリクトを提示 択一選択 既存のスタイルとの競合があります。プレビューで保持するか置換するか選択してください。 プレビューで保持または置換を択一で選択
catalog_id 発生タイミング 条件 処理 ユーザー向け表示 復帰導線
error.invalid_json_syntax parse JSON.parseに失敗した import不可 JSONが不正です。構文を確認してください。 該当行を修正して再解析
error.empty_json parse 入力が空、または空白のみ import不可 JSONが入力されていません。 JSONを貼り付ける、またはファイルを選択
error.no_tokens_found parse JSONは読めたがimport可能なcolor tokenが0件 import不可 インポート可能なカラートークンがありません。 $type: color / $value / color rootを確認
error.file_read_failed file input 選択ファイルを読み込めない import不可 ファイルを読み込めませんでした。 別ファイルを選択、またはJSONを直接貼り付け
error.conflict_check_failed pre-import 既存のFramer Color Style一覧を取得できない 一時停止 既存のColor Styleを確認できませんでした。 再試行。権限やFramer API状態を確認
error.insufficient_permissions import FramerのColor Style作成・更新権限がない import不可 権限が不足しています。 編集権限のあるプロジェクトで再実行
error.import_failed import Framer Color Styleの作成・更新に失敗した 対象token失敗 インポートに失敗しました。 失敗理由を表示し、再試行または該当tokenを修正
